LLM Word Roulette

Interactive baseline dashboard for random-word distributions.

How to read this page

1) Use the rank plot to compare distribution shape (all curves overlap there). 2) Use Top-20 bars for concrete words. 3) If Ollama runs are present, compare no-RAG vs random-RAG behavior and the overlap chart against P_freq.

Baselines: P_freq = word frequency in Shakespeare, P_type = uniform over vocabulary, P_salience = characteristic Shakespeare words.

Ollama model runs

This panel shows model sampling runs. If `rag_mode=random`, each request gets a random corpus chunk prepended before asking for the random word.
